# RXData Editor

A dual-pane editor for **RXData files** (.rxdata) - Ruby Marshal save files used by RPG Maker games.

## What is this?

This app lets you edit RXData files from RPG Maker games. You can view and modify game data, transfer objects between files, and edit values safely without corrupting your saves (if you are doing it correctly).
I recommend making a copy of your RXData files before editing them.

## Features

- Load two RXData files side-by-side
- Copy/paste objects and data between files
- Search for specific attributes or values
- Edit values directly in a clean interface
- Safe saving that prevents file corruption

## How to install

1. Download `RXData Editor 1.0.0.exe` from [Releases](../../releases)
2. Run it - no installation needed!

## How to use

1. **Load files**: Click "Load Left File" and "Load Right File"
2. **Browse**: Use the tree on the left to explore the Ruby objects
3. **Search**: Type in the search box to find specific data quickly
4. **Edit**: Click on values to change them
5. **Copy/paste**: Select objects and use Ctrl+C / Ctrl+V to copy between files
6. **Save**: Click "Save Left" or "Save Right" when done

**Always backup your RXData files before editing!**
