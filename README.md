# RXData Editor

A dual-pane save file editor for **Pokemon Empyrean** (.rxdata files).

## What is this?

This app lets you edit Pokemon Empyrean save files. You can transfer Pokemon between saves, edit stats, change money, and modify other game data safely.

## Features

- Load two save files side-by-side
- Copy/paste Pokemon and items between saves
- Search for specific Pokemon or attributes
- Edit values directly in a clean interface
- Safe saving that prevents file corruption

## How to install

1. Download `RXData Editor 1.0.0.exe` from [Releases](../../releases)
2. Run it - no installation needed!

## How to use

1. **Load files**: Click "Load Left File" and "Load Right File"
2. **Browse**: Use the tree on the left to find what you want to edit
3. **Search**: Type in the search box to find Pokemon or attributes quickly
4. **Edit**: Click on values to change them
5. **Copy/paste**: Select something and use Ctrl+C / Ctrl+V to copy between files
6. **Save**: Click "Save Left" or "Save Right" when done

**Always backup your save files before editing!**
